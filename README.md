# ConcordBatch

ConcordBatch is a contract-only GenLayer Intelligent Contract primitive. Three
wallet-authenticated participants submit bounded action intents for two funded
execution slots. Validators agree on the complete pairwise conflict and order
graph; deterministic contract code selects one compatible pair, grants one-time
execution tickets, and opens fixed GEN credits.

Status: specification in progress. No deployment or network lifecycle is
claimed yet.
